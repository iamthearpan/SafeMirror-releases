# SafeMirror

A safe, one-way backup app for external drives on the Mac. It only **copies** — it never deletes anything from your backup by itself —
keeps the older version of every file you change, waits while Logic / Pro Tools / DaVinci … are open, and can back up by itself in the background.

## Download

**[Download the latest SafeMirror (.dmg)](https://github.com/iamthearpan/SafeMirror-releases/releases/latest/download/SafeMirror.dmg)**
· [all versions](https://github.com/iamthearpan/SafeMirror-releases/releases)

Requires macOS 14 or newer (Apple Silicon and Intel).

## Install
1. Open the downloaded `.dmg` and drag **SafeMirror** onto the **Applications** folder.
2. The first time, open it with **right-click → Open → Open**. This early version is not yet notarized by Apple, so macOS asks once.
3. Follow the short setup: choose your work drive, your backup drive, and the folders to protect.
